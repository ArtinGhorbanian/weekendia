# License Decision Record

## Decision

Do not add a `LICENSE` file and do not publish this repository publicly. Keep
the repository private until the rights and provenance evidence below has been
collected, reviewed, and recorded.

The absence of a `LICENSE` file means no open-source permission is being
offered. It does not establish ownership, authorship, exclusivity, or permission
to redistribute any pre-existing material.

## Current evidence gap

The available workspace contains no reliable record establishing the origin of
the initial source, contributor permissions, asset provenance, product-name
clearance, or the terms under which the work was created. There is also no prior
repository history or license record available for verification.

## Evidence required before a public license decision

Collect and review all of the following:

1. A dated provenance record for every pre-existing source file, including the
   original repository or delivery source and its complete license history.
2. Contributor records and written permission sufficient for the intended
   license and distribution model, including any applicable work-for-hire,
   employer, client, or contractor terms.
3. Records for any starter repository, template, generated code, copied snippet,
   or external design system, including required attribution and downstream
   license obligations.
4. Source and license evidence for the favicon, every inline SVG, typography,
   screenshots, and any future media assets.
5. Clearance for the project and product names and any marks intended for public
   presentation, including the AIONEX project identity where used.
6. A reviewed third-party dependency inventory, including resolution of the
   ambiguous `socksio` license metadata and preservation of required notices.
7. A clean secret scan of the complete history intended for publication, plus
   confirmation that any credential ever stored in a synced or tracked location
   has been handled under the applicable credential policy.
8. Written approval from the party authorized to choose the outbound license,
   publication scope, and commercial terms.

## Reassessment output

If the evidence is completed, document the reviewer, date, evidence locations,
chosen outbound license, attribution requirements, asset exceptions, and any
distribution restrictions before changing repository visibility. Until then,
private evaluation is the only approved repository posture.
